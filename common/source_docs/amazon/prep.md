[Amazon (amazon schema) 데이터 검증 결과]
========================================

1. review.timestamp는 밀리초 epoch 정수입니다.
2. meta.price는 문자열이고 유효 값은 약 20%입니다. 숫자 결측을 0으로 채우지 마십시오.
3. meta.description은 47.5%가 빈 목록입니다.
4. review.helpful_vote에 일부 음수 이상값이 있습니다.
5. title, text는 영문 자유 텍스트입니다. 일반 NLP 전처리(형태소 분석 등)는 하지 않습니다.
