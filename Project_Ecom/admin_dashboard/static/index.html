기록을 불러오지 못했습니다.

서버 연결을 확인한 뒤 다시 시도해 주세요.

01

실행 방법

admin_app 폴더를 slack_bot.py와 같은 프로젝트 폴더에 넣고 실행하세요. 프로젝트 경로를 자동으로 찾습니다.

python admin_app/run_dashboard.py

관리자 계정 입력 후 서버가 시작되고 브라우저가 열립니다.

02

기록 읽기

프로젝트의 logs/app.log와 날짜별 로그를 읽습니다. 로그를 수정하거나 에이전트·LLM을 실행하지 않습니다.

자동 선택한 경로가 다르면 --project 옵션으로 실제 프로젝트 폴더를 지정하세요.

03

상태 해석

검증 필요는 종료 기록은 있지만 분석 성공을 확정할 근거가 없는 요청입니다. 종료 미확인은 종료 기록이 없는 요청입니다.

기록되지 않은 최종 답변·파일·Slack 전송 결과는 미기록으로 표시합니다.

04

접속과 조회 범위

다른 PC는 같은 네트워크에서 서버 PC의 IPv4 주소와 포트로 접속합니다. 방화벽 허용이 필요할 수 있습니다. 내 PC에서만 사용할 때는 --local-only 옵션을 사용하세요.

최근 로그 15개에서 파일당 최대 약 4MB, 기존 운영 DB가 있다면 최근 5,000건을 읽습니다. 범위 밖의 기록은 통계에 포함되지 않습니다.
