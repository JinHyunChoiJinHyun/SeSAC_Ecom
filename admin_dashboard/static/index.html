운영 현황

분석 요청의 흐름과 처리 결과를 확인하세요.

CSV 내보내기
기록을 불러오지 못했습니다.

서버 연결을 확인한 뒤 다시 시도해 주세요.

01

실행 방법

프로젝트 폴더(slack_bot.py가 있는 곳)에서 실행하세요. 프로젝트 경로를 자동으로 찾습니다.

python admin_dashboard/run_dashboard.py --local-only

다른 PC에서 접속해야 할 때만 --local-only를 빼고, 관리자 계정을 입력한 뒤 사용하세요.

02

기록 읽기

프로젝트의 logs/app.log와 날짜별 로그를 읽습니다. 로그를 수정하거나 에이전트·LLM을 실행하지 않습니다.

자동 선택한 경로가 다르면 --project 옵션으로 실제 프로젝트 폴더를 지정하세요.

03

상태 해석

처리 중은 시작 후 30분 안에 종료 기록이 없는 요청, 종료 미확인은 30분이 지나도 종료 기록이 없는 요청입니다. 검증 필요는 종료 기록은 있지만 분석 성공을 확정할 근거가 없는 요청입니다.

워크플로 단계가 멈춘 요청은 실패로 집계하고, 상세 화면에 이유를 표시합니다.

04

접속과 조회 범위

다른 PC는 같은 네트워크에서 서버 PC의 IPv4 주소와 포트로 접속합니다. 방화벽 허용이 필요할 수 있습니다.

최근 로그 15개에서 파일당 최대 약 4MB를 읽습니다. 범위 밖의 기록은 통계에 포함되지 않습니다.
